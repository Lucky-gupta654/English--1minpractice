SPIN & SPEAK — ENGLISH SPEAKING PRACTICE

Open index.html in a current browser. The site uses only local HTML, CSS,
JavaScript, and browser localStorage; it needs no server or internet connection.

Spin for a prompt, choose a category and difficulty if you like, then press
Start to begin the 60-second timer. Pause/Resume and Restart are available.
The Surprise Me and Next Topic buttons select another unused prompt instantly.

The 500 prompt IDs, used-question cycle, notes, practice totals, daily goal,
theme, and recent history are saved in this browser. Browser privacy settings
can restrict localStorage on file:// pages; in that case the site warns you and
keeps the current run in memory. Use Reset Questions to start a fresh prompt
cycle for the selected category (or all categories).
